# ecommerce

🎯OBJETIVO : 
Realizar un ecommerce que tenga una temática libre  es decir contruir un sitio web que simule la compra venta de productos. Para observar la conservación de datos y paso de los mismos por la pagina  mientras el usuario siga en la pagina web.

📝 REQUISITOS:
1. Gestión del carrito: crear una función que reciba un id
de un producto y lo guarde en un array
2. Calculo del total con el objetivo de sumar precios para el cálculo del envío
3. Filtrar por una categoría
4. Ordenar los productos de menor a mayor precio (función sort)
5. Simulación de la sesión de usuario
6. El sistema debe de tener varias categorias
